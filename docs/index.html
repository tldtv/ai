Alex lands $20M to automate AI recruiting workflows

HR-techМировойкластер C-AIR-01
Идея из новости

Компания Alex привлекла $20M ($17M Series A + $3M seed) на платформу, автоматизирующую этапы найма: видео/телефонные интервью, скрининг резюме, планирование, детекцию мошенничества, ATS-интеграцию. Инвесторы: Peak XV Partners, Y Combinator, 1984 Ventures. Крупный раунд на end-to-end автоматизацию воронки найма показывает, что инвесторы делают ставку на полный AI-найм, а не на точечные функции — вызов для AIR, который пока закрывает отдельные этапы, а не всю воронку.

Применимость для Авито

Расширить AIR от точечного AI-скрининга к end-to-end автоматизации воронки (интервью + fraud-детекция + ATS-интеграция) как апсейл-модуль для HR-tech клиентов Авито.Работы.

Branch: Expanding Earned Wage Access - the new Flex model

ПодработкаРФ/ТГкластер C-EWA-01
Идея из новости

Branch выпустил конфигурацию Flex для earned wage access (EWA), убирающую необходимость интеграции с payroll/time-tracking системами клиента; срок внедрения сокращается с месяцев до недель. Ориентирован на staffing-платформы, маркетплейсы, hospitality и workforce management системы. Снижение барьера интеграции EWA сигнализирует, что рынок embedded-финтеха для gig/staffing переходит от «сложно внедрить» к «подключаемая функция» — окно для быстрого запуска EWA у платформенных игроков расширяется, а не сужается.

Применимость для Авито

Добавить мгновенный вывод заработанного (earned wage access) как встроенную функцию в Авито.Подработку через партнёрство с платёжным провайдером вместо самостоятельной разработки инфраструктуры.
